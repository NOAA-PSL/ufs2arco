.. list-table:: Variables from CONUS404 available in ufs2arco
   :header-rows: 1
   :widths: 18 50

   * - Variable
     - Long Name
   * - ``P``
     - Total pressure (P0 + PB)

   * - ``U``
     - U-component of wind with respect to model grid

   * - ``V``
     - V-component of wind with respect to model grid

   * - ``W``
     - W-component of wind

   * - ``Z``
     - Geopotential height (PH + PHB)/9.81

   * - ``LH``
     - Latent heat flux at the surface

   * - ``MU``
     - Dry airmass in column (MU + MUB)

   * - ``Q2``
     - Water vapor mixing ratio at 2 meters

   * - ``SR``
     - Fraction of frozen precipitation

   * - ``T2``
     - Temperature at 2 meters

   * - ``REFL_10CM``
     - Radar reflectivity (lambda = 10 cm)

   * - ``ACRAINSNOW``
     - Accumulated rain on snow pack (accumulated over prior 60 minutes)

   * - ``I_ACLWDNBC``
     - Bucket for downwelling clear sky longwave flux at bottom accumulated since model start

   * - ``I_ACLWDNTC``
     - Bucket for downwelling clear sky longwave flux at top accumulated since model start

   * - ``I_ACLWUPBC``
     - Bucket for upwelling clear sky longwave flux at bottom accumulated since model start

   * - ``I_ACLWUPTC``
     - Bucket for upwelling clear sky longwave flux at top accumulated since model start

   * - ``I_ACSWDNBC``
     - Bucket for downwelling clear sky shortwave flux at bottom accumulated since model start

   * - ``I_ACSWDNTC``
     - Bucket for downwelling clear sky shortwave flux at top accumulated since model start

   * - ``I_ACSWUPBC``
     - Bucket for upwelling clear sky shortwave flux at bottom accumulated since model start

   * - ``I_ACSWUPTC``
     - Bucket for upwelling clear sky shortwave flux at top accumulated since model start

   * - ``SNOWENERGY``
     - Energy content in snow relative to 273.16 K

   * - ``SOILENERGY``
     - Energy content in soil relative to 273.16 K

   * - ``PREC_ACC_NC``
     - Accumulated grid-scale precipitation over prec_acc_dt (accumulated over prior 60 minutes)

   * - ``SNOW_ACC_NC``
     - Accumulated snow water equivalent over prec_acc_dt (accumulated over prior 60 minutes)

   * - ``REFL_1KM_AGL``
     - 1 km AGL reflectivity

   * - ``GRAUPEL_ACC_NC``
     - Accumulated graupel water equivalent (accumulated over prior 60 minutes)
